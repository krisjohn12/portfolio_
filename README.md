A single-page personal portfolio site for Kris-John O. Martinez, a 3rd year
Information Technology student. Built as a static site with plain HTML, CSS,

## About This Project

This portfolio introduces Kris-John, lists the languages he's currently practicing
with (HTML, CSS, JavaScript, Python, Java), and showcases two sample projects built
during coursework and self-study. The design borrows visual language from technical
and engineering drawings — a title-block header, graph-paper background, numbered
"drawing sheets" for each project, and blueprint-style diagrams — to reflect a
"still drafting" theme for a student who's still building up his skills.

## Sections

| Section | What it contains |
|---|---|
| **Home** | Intro, name, and a title-block table with course, year level, and status |
| **About** | A "layer legend" listing the languages/tools currently being learned |
| **Projects** | Two sample projects (`calcpad`, `stocktrack`), each presented as a numbered sheet with a description, duration, tech stack, an optional feedback note, a blueprint-style diagram, and links to the live demo and source code |
| **Contact** (footer) | Email, GitHub, and LinkedIn, laid out as a revision log |

## Featured Projects

- **calcpad** — A basic calculator app supporting addition, subtraction,
  multiplication, and division, built with a simple button-grid interface.
- **stocktrack** — A simple inventory management system for adding items,
  logging stock in/out, and viewing current quantities on hand.

## Built With

- **HTML5** — page structure
- **CSS3** — layout, theming, and responsive design (no external CSS frameworks)
- **JavaScript (vanilla)** — active nav-tab highlighting on scroll
- **Google Fonts** — Big Shoulders Display, Work Sans, IBM Plex Mono
